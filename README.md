Парсер расписания КАИ (ИКТЗИ)

Консольное приложение на Python для получения актуального расписания занятий групп ИКТЗИ КНИТУ-КАИ и вывода его в виде красивой таблицы в терминале.

Стек технологий
- Python 3.8+
- Requests — для отправки POST-запросов к внутреннему API сайта КАИ.
- Rich — для красивого форматирования и вывода таблиц в консоль.
- Unittest — для написания Unit-тестов.
Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/rubtsova908/kai-parser.git
2. Перейдите в папку с проектом:
cd kai-parser
3. Установите необходимые библиотеки:
pip install -r requirements.txt
4. Запустите программу:
python main.py
5. Введите номер группы (например, 4101 или 4123), и программа выведет расписание.
Для проверки стабильности программы предусмотрены Unit-тесты:
python -m unittest test_parser.py
Структура проекта
main.py — главный файл, точка входа (интерфейс командной строки).
parser.py — модуль для поиска ID группы и получения JSON с расписанием.
formatter.py — модуль для обработки JSON и вывода таблицы с помощью rich.
test_parser.py — файл с Unit-тестами.
requirements.txt — список зависимостей.
